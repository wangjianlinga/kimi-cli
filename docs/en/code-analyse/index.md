# Code Analyse

This section covers how to use Kimi Code CLI for code analysis tasks.

## Overview

Kimi Code CLI can analyze codebases, identify issues, suggest improvements, and help you understand complex projects through natural language interaction.

## Getting Started

Start a session in your project directory:

```bash
kimi
```

Then ask the agent to analyze your code:

```
analyze the architecture of this project
```

## Common Tasks

- Architecture analysis
- Code review
- Bug investigation
- Refactoring suggestions
- Dependency analysis
